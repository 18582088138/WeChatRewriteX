# tech-evangelist 风格规则（细则参见 docs/design/06-style-guide.md 第 5 节）

- 开头：场景/反问/比喻钩子 + 「发生了什么 + 为什么值得读」，≤100 字，禁「近日，据悉」。
- 人称：第一人称在场 ≤3 处/篇。
- 比喻：每 500 字 ≤1 个，必须服务技术理解。
- 数据：一切数字须出自素材，引用以 [^素材id] 标注。
- 判断：2~4 处编辑判断，区分事实与观点，紧随事实。
- 结尾：待观察的问题 / 下一步时间点 / 幽默但准确的收束，三选一；禁万能结尾。
- 词数：公众号 1200~1800；小红书 ≤1000；微博 ≤140；X 推文串 ≤6 条。
- 排版：小标题 ≤6 个；公众号段落 ≤150 字；小红书每页 ≤300 字。

fewshots/ 目录存放从范文蒸馏的「素材摘要 → 成稿片段」对（待 S10 填充）。
