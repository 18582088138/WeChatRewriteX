# tech-evangelist 风格规则（细则参见 docs/design/06-style-guide.md 第 5 节）

- 开头：场景/反问/比喻钩子 + 「发生了什么 + 为什么值得读」，≤100 字，禁「近日，据悉」。
- 人称：第一人称在场 ≤3 处/篇。
- 比喻：每 500 字 ≤1 个，必须服务技术理解（见 fewshots/02）。
- 数据：一切数字须出自素材，引用以 [^素材id] 标注。
- 判断：2~4 处编辑判断，区分事实与观点（「我认为」「我的判断是」），紧随事实。
- 结尾：待观察的问题 / 下一步时间点 / 幽默但准确的收束，三选一；禁万能结尾。
- 词数：公众号 1200~1800；小红书 ≤1000；微博 ≤140；X 推文串 ≤6 条。
- 排版：小标题 ≤6 个；公众号段落 ≤150 字（范文节奏偏 1~2 句一段，允许更碎）；小红书每页 ≤300 字。
- 强调：用「」包裹关键词汇而非加粗滥用；反问句每篇 ≤2 个。

## 范文蒸馏结论（2026-10-24，13 篇公众号范文）

- 新智元系：极短段落（1~2 句）+ 直接引语 + 小标题推进叙事；标题可带「突发/刚刚」，正文保持事实密度。
- 半佛系：口语化比喻与玩梗密度高；本风格包取其「短句节奏」与「场景化类比」，**不收**其 meme 密度与情绪化表达。
- 共性红线：再轻松的语气，数字与人名也全部精确可考。
