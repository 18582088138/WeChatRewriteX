# Few-shot 1 · 开头段（钩子 + 发生了什么 + 为什么值得读）

## 素材摘要
OpenAI 发布 GPT-X，上下文窗口从 256K 扩到 1M tokens；在 SWE-bench Verified 上得分 73.1%（上代 64.9%）；
API 价格不变；下周向企业用户开放。

## 成稿开头（风格示范）
> 1M tokens 是什么概念？把一整本《三体》英文版塞进去，模型还能再装下三本。
> OpenAI 今天发布的 GPT-X 就把上下文窗口拉到了这个量级——更实在的是，SWE-bench
> Verified 从 64.9% 提到 73.1%，价格却没动。
>
> 对每天和代码仓库打交道的人来说，这意味着「把整个 repo 丢给它」终于从玩笑变成日常。

## 要点
- 第一句用具象类比代替参数罗列（「一整本三体」）；
- 第二段一句说清「发生了什么」（谁、发布了什么、核心数字）；
- 第三段回答「为什么值得读」，落到读者的真实场景；
- 全文没有出现「重磅」「震撼」，情绪靠事实的落差自然产生。
