# V1.18：侧窗、卡片字体与审稿媒体修复

版本：1.18.0，基于 main 的 V1.17.1。无数据库迁移，工作版本/定稿与固定 exports 规则保持不变。

## 宽屏侧窗唤出

原因：边缘悬停处理在宽屏条件下直接返回，手动收起后虽然有边缘标记，却无法再次展开。

修复：宽屏和窄屏都支持边缘悬停 0.5 秒展开，也支持点击及键盘激活。切换屏幕宽度时取消旧的悬停/收起定时器。宽屏展开后保持常驻，窄屏保留移出后自动收起行为。

## 小红书卡片正文统一字号

原因：模板对每张内容卡片分别缩字号，字数、插图和末页品牌区的差异使各页得到不同字号；封面摘要又使用独立固定字号。

修复：先等待字体和插图尺寸就绪，再为整组卡片选择同一个正文适配字号。普通段落、引用段落和封面摘要一致；标题、页脚等保持各自层级。最拥挤的一页决定整组正文的字号，不低于主题的最小值；仍无法容纳的内容保留溢出告警，不删除或截断原文。预览 HTML 和实际 PNG 使用同一版式。

文件 URL 统一通过 `Path.as_uri()` 生成，支持素材和输出目录中的空格、中文及 `#` 等字符。

影响：较短页面可能随密集页面一起变小，整组视觉更一致。等待资源加载替代固定延迟，避免图片晚加载后挤压文字。旧导出 PNG 需重新生成才能应用新排版，不会自动覆盖既有文件。

## 审稿图片和视频显示

原因：V1.17 新增删除按钮后，媒体节点的 `v-else-if` 接在删除按钮的 `v-if` 后；图片/视频先命中按钮条件，正文媒体分支因此不会渲染。

修复：媒体仍按正文类型渲染，删除按钮作为独立节点。图片显示与视频原生播放恢复，保留视频图注和删除能力；删除一个媒体块不影响其他块或自动升正式版本。

## 验收与交付

99 项后端回归、7 项真实浏览器流程、Vue 严格类型检查与构建通过，独立 wheel 安装验收通过。Windows 新程序已完成四平台隔离验收。安装包与构建命令见 [ARTIFACTS.md](ARTIFACTS.md)。本轮覆盖实际 Chromium 卡片尺寸/字号、宽窄屏侧窗唤出、审稿图片解码与 WebM 视频播放，以及媒体删除后的工作版本。

Windows 继续使用 exe + `_internal/` 目录式绿色包，升级时整体替换程序文件，并保留个人配置与数据。
