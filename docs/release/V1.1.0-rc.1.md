# 文枢 V1.0+ 候选版 1.1.0-rc.1

候选版增加小团队共享项目、成员身份与人工审核，保留 Vue/FastAPI/SQLite、单实例队列、素材归档和四平台发布包。
正式 main/v1.0 保持原版；此候选尚未通过家庭主机部署及外地成员最终验收，没有发布正式 GitHub Release。

## 功能与权限

- 管理员管理成员、系统和项目，维护负责人在授权项目内定稿及生成发布包，普通成员创作/审核并下载既有发布包。项目负责人单独分配创作、审核或只读权限。
- 每位成员有独立账号与会话；旧共享令牌不能代替成员登录。旧项目初始管理员私有，公共素材必须显式共享，复制素材生成独立项目文件。
- 人工审核提交固定内容及素材快照，支持指派、意见、退回、批准、撤回和改派，默认允许自审。内容变化使批准过期；AI审稿状态独立，管理员例外必须说明原因并留痕。
- 保存检查项目与正文revision，保留冲突输入；后台任务记录发起人，迟到结果和执行中撤权不能覆盖内容。占用提示、工作列表及审计支持协作。
- 独立持久运行目录、离线完整备份、隔离恢复与停服务本机管理员恢复；提供 Windows/systemd/Compose 和 HTTPS/私有组网材料。

使用方法见[团队手册](../v1-plus/user-guide.md)，安装与网络步骤见[S6维护手册](../v1-plus/S6-operations.md)，验证证据和未验收项见[S7记录](../v1-plus/S7-acceptance.md)。
不增加 TTS、视频制作、自动发布、独立worker或实时共同编辑。

## 数据升级与回退

软件显示 `1.1.0-rc.1`，Python 分发版本规范化为 `1.1.0rc1`；数据库从正式 v1.0 的 schema3 升至 schema6。
增加成员/会话/ACL/共享/审计、人工审核/意见/定稿关联及占用/任务计时，不改变旧文稿与归档文件格式。
旧定稿和导出可读；旧定稿生成新导出前需要人工记录或管理员明确例外。旧无责任任务需管理员确认接管。

升级前停服务，使用旧程序的完整备份功能保存数据库、素材、配置与密钥；正式 v1.0 不带新备份CLI时，按[S1维护手册](../v1-plus/S1-operations.md)使用S1程序执行备份。
在新程序目录启动迁移，使用原持久目录，并由管理员核对旧项目、文件和成员授权后再邀请成员。
回退前保留升级后新增内容，停服务并将完整旧备份恢复到全新目录，使用与备份匹配的旧程序及显式数据/日志目录启动。
切换 Git 分支不会恢复数据库，不可直接用旧程序读取升级后数据库。

## 候选文件与验收

本机候选产物位于 `release/v1.1.0-rc.1/`，包括 Windows x64 zip、Python wheel、源码 tar.gz 和 SHA256SUMS.txt；详见[产物清单](ARTIFACTS.md)。
Linux 独立二进制未生成；wheel 的 Windows 安装验证不能代替家庭系统安装或 Docker/Linux 实测。
候选包不包含真实用户数据、密码或模型密钥。

阶段分支 `dev/v1-plus-s0`～`dev/v1-plus-s7` 保留，集成分支 `dev/v1-plus` 用于完整验收。
逐阶段复验必须使用独立测试目录与匹配数据，尤其不要让旧阶段程序连接已升级的真实数据库。
真实家庭硬件/网络、手机实机、外地协作、另一设备备份与3～7日试运行仍须补验；当前只能报告本地候选完成。
