# 文枢 v1.0：图文内容创作基础功能

发布日期：2026-10-30。Git 标签：`v1.0`。程序及 Python 包版本：`1.0.0`。

本次将开发迭代 V1.18 的完整成果确立为首个正式版，完成开发计划「V1.0：实现图文内容创作的基础功能」。
此前 V1.1～V1.18 是开发过程中的迭代编号，保留对应提交和文档；正式发布序列从 v1.0 开始，之后修复为 1.0.1，兼容的新功能为 1.1.0。

## 已提供的功能

- 链接、本地文件及项目文件夹录入，正文与图片/视频素材收集和管理。
- 资料收集、AI 图文创作、审稿流程，支持人工编辑、配图与审稿意见采纳。
- 工作文稿持续保存、定稿封存、历史读取与回滚，定稿后继续编辑自动进入下一版文稿。
- 公众号 HTML、小红书分页图文卡片、微博正文及媒体清单、X 帖文串及媒体清单导出。
- 本地设置、环境变量热加载、日志与 Windows 一键启动。
- 包含 V1.18 的侧窗展开、卡片统一字号、审稿图片和视频显示修复。
- 修复 CI 安装包任务缺少构建工具、Docker 引用不存在依赖锁文件的问题，构建依赖使用当前 requirements.txt。

四个平台均通过导出文件后手动发布。API/RPA 自动发布、移动端与云端同步属于后续开发范围。
真实 AI 创作需要配置模型密钥；无密钥时可以运行程序和体验降级流程。

## 下载与安装

[GitHub Release](https://github.com/18582088138/WeChatRewriteX/releases/tag/v1.0) 提供：

- `文枢-v1.0.0-windows-x64.zip`：Windows x64 绿色包，解压后双击 `启动文枢.bat`；包含 exe、`_internal/`、当前前端、Chromium、启动脚本及文档。
- `wenshu-1.0.0-py3-none-any.whl`：Python 安装包，适用于已有 Python 环境的用户；依赖需单独安装，首次使用卡片功能需安装 Chromium。
- `wenshu-1.0.0.tar.gz`：Python 源码分发包，含运行资产与构建/测试源文件。
- `SHA256SUMS.txt`：以上三个附件的 SHA256 校验值。

GitHub 自动提供的 Source code zip/tar.gz 是 Git 源码快照，直接运行需要自行构建前端。
本次没有提供 Linux 独立二进制或预构建 Docker 镜像；Linux 可按 [部署说明](DEPLOY.md) 使用源码/Python 包或自行构建。

在 PowerShell 验证 Windows 附件：

```powershell
Get-FileHash '.\文枢-v1.0.0-windows-x64.zip' -Algorithm SHA256
```

将输出与 `SHA256SUMS.txt` 中同名文件的值比较。

## 从开发迭代 V1.18 升级

本次正式编号调整不引入数据库迁移，沿用已有 schema v3。1.0.0 虽然数值低于旧开发编号 1.18.0，功能基线来自 V1.18 的最新 main。

1. 停止旧程序，备份完整 `.env`、`config/`、`resource/`，需要时保留 `log/`；备份方法见 [架构与升级说明](../ARCHITECTURE.md)。
2. 将 v1.0 解压到新目录，迁移个人配置与数据；程序文件使用新包的 exe、`_internal/` 和 `web/dist/`。
3. 启动新程序，核对文章、素材和文稿；旧卡片需要重新导出才能应用最新排版。

需要回退时停止程序，恢复对应版本的完整数据备份并启动原程序。单纯切换 Git 分支不会恢复用户数据。
