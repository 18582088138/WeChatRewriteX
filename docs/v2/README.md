# V2 音频创作重新开发验收入口

本次按用户要求从 main `bf24cac` 重新实施 S0～S9，每阶段独立分支、源码提交与新验证；旧集中实现只作参考，不进入新系列祖先。最终开发分支为 `dev/v2-audio`，软件版本 **1.2.0-rc.2**，逐阶段记录见 [重建入口](rebuild/README.md)。阶段分支只保留在本地，远端仅保留最终开发分支，按 [commit 清单](rebuild/commits.md) 拉取指定阶段复验。

功能包含独立口播/历史/来源、保守或 AI 派生与读法、已有 MiniMax 声音档案、持久合成/缓存/额度/恢复、工作台、人工审批/正式导出、发音词典/混音/响度和段落字幕。重建另补强首次保存来源绑定、空清单兼容、阶段能力开关、后处理升级失效规则和过期字幕候选限制。

开始验收：[使用说明](user-guide.md)、[维护/回退](operations.md)、[API 契约](api-contract.md)。本次开发与最终包检查记录在 [S9](rebuild/S9.md) 及本机 `build/v2-rebuild-evidence/`。

历史真实 TTS 共 2 次/64 个发送字符：首次余额不足，用户更新 `.env` 后成功生成约 4.90 秒 MP3；见 [历史补验](S3-api-recheck-2026-11-06.md)。本次重新开发新增真实 API/声音克隆/样本上传/远端声音删除 **均为 0 次**，没有清零历史调试额度。

真实 2～5 分钟主题、真人读音/自然度、NUC 升级、手机/跨网络、持续运行和用户终审仍待验收；既有 V1.0+ 未完成项继续保留。V2 本次候选不合入 main、不部署、不发布 Release，旧 v1.0/v1.1.0-rc.1 和 v1.2.0-rc.1 包保留。
