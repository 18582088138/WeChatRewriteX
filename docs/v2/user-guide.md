# 音频创作使用说明

## 从图文派生口播

打开主题项目，在“音频创作”页设置听众、人设、语言和 2～5 分钟目标时长，点击“从图文派生口播稿”。保守派生保留事实和来源位置；勾选 AI 会使用已有 LLM 配置改为口播结构，并记录模型费用。关键数字改变或来源结构异常时拒绝保存 AI 结果。

展示文本与发音文本分别保存。默认根据规则转换日期、百分比、型号、单位、英文缩写及引用标记；需要人工读法时勾选“手工指定读法”。词典可把 NVIDIA 等专名映射为读法，保存后自动文本中使用该词的段落改变，其他段落可复用。

段落可新增、编辑、重排、删除和 AI 局部改写，稳定 ID 与历史版本保留。编辑后点击“保存口播与设置”；发生冲突会保留本地输入，允许对照服务器最新口播后显式继续编辑。离开有未保存输入的项目会提示。图文与口播独立编辑；图文来源改变时须重新派生或确认复核。

## 选择已有音色和生成

管理员在本项目登记已有 voice ID、显示名、来源/授权说明；登记并不创建远端声音。已登记声音只能用于明确授权的项目。用户默认音色通过服务端 `MINIMAX_DEFAULT_VOICE_ID` 配置；个人模式或管理员首次派生时可登记到本项目，普通成员不能自动管理声音。

选择获准声音、模型和参数后保存。点击“估算本次调用”查看未命中片段、发送字符、预计费用与缓存。中文计费字符与发送字符不同：MiniMax 中国区一个汉字计两个计费字符；界面费用始终为估算/待核对。未知费率不会显示成免费，HD 费率不会套用到 Turbo。

点击整段生成或段落更新。同输入复用缓存，修改一段只生成受影响片段；重排、删除、段后停顿和纯混音修改只做本地处理。改变全局声音参数会使多个片段失效。实际时长由 FFprobe 和解码测量，超出策划目标需调整脚本。

段落和完整音频都有播放器，草稿试听与正式批准分开。排队取消阻止后续发送；已经发送后取消不能保证不收费。超时/进程中断的响应未知不会自动重发；明确选择重试可能重复收费。错误 `1008` 表示 MiniMax 余额不足，先处理账户条件。

## 审核与导出

规则和可选 AI 口播审阅提供意见，不代替人工批准。提交口播快照给有项目审核权限的成员，填写意见、退回修订或人工批准；按现有团队自审策略执行。生成完整音频后提交成品试听确认，指定审核者听完后显式批准。

维护负责人或管理员可核验批准并导出。普通成员可在当前项目 ACL 下播放/下载已授权成品。导出 ZIP 包包含 MP3、WAV、展示稿、发音稿、SRT/VTT 和清单，保留声音参数、来源、批准关联、时长和 SHA256。稳定正式 MP3 入口指向完整已批准版本；失败不替换上一份，旧批次不覆盖更新导出。

修改口播使对应声音与成品待更新；纯声音/混音修改不会删除未变化的口播批准历史，但新成品需再次试听批准。音频历史仍可读取，按当前项目 ACL 检查，撤权后旧 URL 也不能继续下载。

## 混音和字幕

片头、片尾、背景音乐从已登记的项目音频素材选择，须填写来源/许可说明。支持裁切、背景循环、淡入淡出、旁白优先压低背景以及两遍响度处理；报告记录成品实测 LUFS/真峰值。工具缺失、素材无效、空间不足或削波风险会拒绝完成，保留已有成品。

字幕仅提供实测段落时间映射，不按字符数均分时长，也不声称逐字精确对齐。可预览/修正字幕文本与时间，修正创建独立候选版本，不改变声音稿或已批准旧字幕。新字幕候选须重新确认成品。
