# 单项事实证据模板

复制到`runs/<run-id>/evidence/<case-id>-<attempt>.md`，替换全部占位项再record。未填事实不能作为passed。JSON/CSV可作为附件；原始私有日志保留在本地，附本地定位与SHA，另提供去敏观察。

- run-id / case-id / attempt：待填
- 执行机器：NUC；型号/系统本次实际值：待填
- 操作者别名、Agent/模型版本（unknown允许）：待填
- repo固定source_commit / 实际执行程序版本、内嵌build commit、包SHA：待填
- 本项依据的CASEBOOK标准及前置编号：待填
- 开始/结束时间（注明UTC或Asia/Shanghai）、实际耗时：待填
- 使用目录与端口（无需用户名/公网地址等无关信息）：待填
- 数据范围：合成固定集／真实数据隔离副本／正式实例的受控测试；实际选择：待填
- 实际命令或UI步骤（不含密码、Cookie、CSRF、密钥）：待填
- 实际观察：返回码、状态转换、文件/数据数量、版本/revision、冲突输入/审批/导出核对；不可只写“正常”：待填
- 自动测试：收集/通过/失败/跳过数量、跳过原因、日志/XML定位；本项未用自动测试则说明：待填
- 人工操作确认：谁确认、注销/重启/手机/外地等实际时段与观察；没有收到确认写“待确认”：待填
- 性能/容量：采样间隔、持续时间、请求数、样本数、P95/内存/CPU/磁盘，以及同时运行的其他负载；不是性能项则说明：待填
- 结果与判定依据：passed/failed/blocked、逐条对应标准；部分通过不可写整项passed：待填
- 失败与重试：首次失败、定位证据、修改/环境变化、复测；无失败写无：待填
- 数据/系统变化、当前服务状态、设置是否恢复：待填
- 回退是否实际演练、步骤与结果；只写方案不等于回退已验证：待填
- 本项未覆盖内容、需要谁提供什么信息及下一步：待填
- 可分享附件及本地原始证据位置/SHA：待填
- 敏感内容检查：已核对无密码、会话凭据、密钥、数据库/备份、真实文章正文；谁核对：待填

公司复核应指出证据能证明什么、不能证明什么。人工确认来自实际操作者，不用Agent推测替代。
