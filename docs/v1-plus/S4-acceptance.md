# S4 人工审核与定稿

新增人工提交快照、指派审核者、退回/批准、撤回/改派、段落/图片/元信息意见及处理状态。
自审默认允许，管理员可关闭；批准固定 version/revision 与正文/素材元信息摘要，不由 AI 结果触发。
定稿需维护负责人或管理员、有效人工批准、现有 AI/规则政策及 CAS；管理员例外须说明原因，仍不能跳过 CAS。
人工批准和定稿关联保留；导出使用定稿资产快照，旧定稿没有人工记录时只读下载既有包，新增导出需管理员显式记录例外。
提交重复点击返回同一待审快照；审批重复意图保持稳定。评论处理不修改内容，过期意见只查看，不自动套用到新正文。
前端新增独立“人工审核”页和固定快照预览，适配窄屏浏览；AI/规则审稿另页保留。

验证：团队隔离进程 pytest 6项通过（26.56秒）；类型检查/生产构建通过。
新增场景覆盖退回修订批准、非指派拒绝、旧版本批准拒绝、自审开关、元信息变更失效、评论状态、角色定稿限制、批准后改稿和导出快照关联。
schema v5 在事务中新增审核/评论/定稿关联表；迁移前自动保存 DB 副本。没有迁移真实用户数据。
真实手机/小主机/外地成员未执行，后台模型均使用测试/无密钥路线，不能报告真实模型验收。
回退需停服务并恢复与旧程序匹配的完整实例备份；旧程序拒绝新schema。升级后意见、成员与稿件先另行保存。
