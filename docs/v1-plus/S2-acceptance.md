# S2 成员身份与授权（开发机）

独立成员登录、管理员初始化/成员管理、强制初始密码更换、重置与会话撤销已实现。
密码使用 Python/OpenSSL scrypt；随机 HttpOnly SameSite Cookie 为8小时，HTTPS下 Secure。
修改请求检查来源和会话 CSRF，登录尝试按来源与账号限流。最后一个管理员不可禁用。
团队模式启用后持久记录在 schema v4，移除环境变量不能恢复共享令牌访问。
列表、搜索、素材文件、历史版本、任务与事件按成员/项目授权；后台任务保存发起人并重新检查权限。

## 数据与操作

设置 `WENSHU_TEAM_MODE=1`；停服务执行 `python -m app --runtime-dir <目录> --init-admin admin`，密码通过交互输入。
也支持至少24字符的临时 `WENSHU_BOOTSTRAP_TOKEN` 首次初始化，完成后移除；不提供公开注册。
旧项目归初始管理员私有，旧公共素材保持管理员私有。迁移前自动 DB 副本仅是辅助，不能替代 S1 完整离线备份。
账号、会话、ACL、审计记录均在原 SQLite 中。程序不写入用户真实目录。

回退：停服务，保存升级后新增数据，再用 S1 完整实例备份恢复到新目录并配套旧程序。不要用旧程序写 schema v4。
`dev/v1-plus-s2` 保留；用户已授权各阶段集成合并，main 正式版不变。
