# 04 · 前端 GUI 设计

## 形态与技术

- **单页应用（第一阶段 PC 优先）**：Vue 3 + Vite + Pinia + Vue Router + TailwindCSS。**已拍板（2026-10-24）：第一阶段功能主体在 PC 端，移动端只做基础响应式可用；第二阶段移动端专职轻量化编辑/修改/操作与素材收集**，届时再补 PWA（添加到主屏幕、离线缓存）。
- 组件策略：**已拍板用 Naive UI**（PC 端表格/弹窗/表单），移动端轻视图用 Tailwind 自绘组件，避免背两套组件库。
- 后端联调：REST + SSE（任务进度）；开发期 Vite dev server 代理到 FastAPI。

## 信息架构

```
/articles                    文章列表 (首页)
/articles/:id                文章工作台
  ├─ tab: 素材               素材面板 (本组 + 公共库)
  ├─ tab: 创作               块编辑器 + 版本
  ├─ tab: 审稿               checklist 面板 + 文档联动
  └─ tab: 发布               平台变体预览 + 推送
/settings                    设置 (LLM/搜索/风格包/平台/存储/Hooks)
```

- 状态徽标三态映射见 `02`；Processing 行显示当前阶段与进度条（SSE 实时）。
- Done 行显示各平台推送结果徽标（成功/失败/未推送）。
- 点击行进工作台，默认落在当前阶段对应的 tab。
- 移动端：卡片列表，左滑出现「重新收集 / 删除」等快捷操作。

## 页面 2 · 工作台 · 素材库 tab（v3，2026-10-25 按规范重做）

- **两大顶层库**（本文素材库 / 公共素材库）切换；**4 个固定分栏标签：文章 / 图片 / 视频 / 其他**（带计数）。
- **拖拽**：公共库素材条目可拖拽到「本文素材库」完成复制（`copy-to-article`，同文件新行不占盘）。
- **文章分栏**：标题（点击看 markdown 原文弹窗）+ 原文链接（点击外跳源网址）+ 参考类型徽标 + 「↻ 重抓/文件夹/删除」。
- **图片分栏**：按来源文章分组（组标题点击跳来源文章正文）；缩略图点击灯箱看大图；左上复选框、右上删除；水印徽标。
- **视频分栏**：同分组；本地视频点击弹窗播放，链接型视频（视频号）点击外跳播放器页，标注「在线播放」；分组标题点击跳来源文章。
- **其他分栏**：音频/文档/链接条目，点击打开所在本地文件夹（`reveal`）。
- **素材增删改查**：粘贴网址（支持批量模式入队 ingest 任务）、上传文件、扫描 inbox（用户直接拷文件到素材目录自动识别）；PATCH 改标题/备注。
- **素材流转创作**：所有条目统一复选框，勾选后点「**导入 & 创作**」→ 勾选集合作为 `selected_material_ids` 传给创作 Agent 启动创作并跳创作 tab。

## 页面 3 · 工作台 · 创作 tab（块编辑器）

核心交互规则（对应需求 #9 #10）：

1. **打开即阅览模式**：渲染精美的只读排版（接近公众号成稿观感），图片/视频内嵌显示。
2. **双击某块进入编辑**：仅该块变为编辑态（textarea / 图片操作条），失焦保存为新版本。
3. **选中块 → 浮动工具条**：
   - 文本块：`AI 重写` `缩写` `扩写` `翻译语体` `自定义指令…`
   - 图片/视频块：`替换（从素材库选）` `移除` `编辑图注`
4. 顶栏：标题候选切换、词数统计、风格包指示、**版本下拉**（v1…vN + 定稿标记 + diff 查看）。
5. 右侧可收起面板：「参考资料插入」（勾选素材段落 + 插入位置 + 指令 → LLM 融合插入，带引用角标）。
6. 每次 AI 操作前弹「将生成新版本」轻提示，操作结果以 diff 视图呈现，可一键撤销（回退到 parent_version）。

## 页面 5 · 工作台 · 发布 tab

- 平台勾选：公众号 / 小红书 / 微博 / X（按 `publish_targets` 启用状态）。
- 每个平台一张**变体预览卡**：公众号渲染 HTML 预览；小红书显示分页卡组（可重新生成卡片、换主题）；微博/X 显示裁剪后的文本 + 话题标签 + 首图。
- 「一键推送草稿箱」逐平台显示结果（成功→草稿箱链接；失败→原因 + 降级动作「导出该平台内容包」）。
- 全程不直发，推送文案明确提示「已存草稿箱，请在平台 App 内最终发布」。

## 页面 6 · 设置

分区：LLM 渠道（key 掩码、连通性测试、用途档位映射）、搜索（窗口天数、参考篇数）、风格包（启用/平台绑定/查看规则）、平台账号（API 凭证或 Cookie 登录向导）、素材库路径、Hooks、备份与导出。

## 移动端适配策略

| 场景 | 策略 |
|---|---|
| 导航 | 底部 TabBar（列表 / 工作台 tabs 收敛为分段控件 / 设置） |
| 编辑 | 单块编辑全屏化，键盘弹出时工具条吸附键盘上方 |
| 审稿 | checklist 与文档分屏改为上下滑动切换，条目吸附底部操作条 |
| 素材 | 网格 2 列，长按多选；**隐藏「资料融合插入」**（需求 #7） |
| 推送 | SSE 降级为轮询（移动浏览器后台挂起时） |
| 网络 | 手机走局域网访问 PC 后端，需访问令牌（见 `01` 安全节） |

## 视觉基调

浅色优先、内容居中型阅读界面；强调色单一（科技蓝/墨绿二选一），卡片化 + 大圆角 + 克制的阴影；小红书预览区可按平台气质换主题。**成稿排版的美观度由卡片模板与公众号主题保证，前端只负责呈现，不做样式硬编码**。
