# WeChatRewritingAssistant

AI 行业要闻（大模型 / 具身智能 / 芯片 / AI 软硬件）的「资料收集 → 再创作 → 审稿 → 多平台草稿箱分发」本地助手。

- 三个 Agent：资料收集、洗稿、审稿，人工审阅定稿
- 输出：公众号 / 小红书（分页卡片组图）/ 微博 / X 平台适配文案，推送至草稿箱而非直发
- 本地优先（conda `xkd_env_py312`），素材与文案全部落盘
